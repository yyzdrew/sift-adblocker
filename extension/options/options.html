Filter lists

Shipped with the extension so blocking works offline from the first run. Refreshing fetches the current version from the publisher.

Custom rules

One rule per line, in EasyList syntax — the same parser the shipped lists go through, so anything valid there works here. Lines starting with ! are comments.

Syntax examples
||ads.example.com^block a domain and its subdomains
||example.com/ads/block a path on one domain
/banner-*.gifblock a URL pattern anywhere (* is a wildcard)
||tracker.io^$third-partyonly when loaded by another site
||cdn.io^$script,imageonly these resource types
@@||example.com/ok.jsexception — never block this
example.com##.promo-boxhide an element on one site

Whitelist

Sites where blocking is switched off. The per-site toggle in the popup writes to this same list. A parent domain covers its subdomains.
